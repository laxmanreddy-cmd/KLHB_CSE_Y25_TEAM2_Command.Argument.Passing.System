# Linux Process Resource Monitoring System

## About the Project

The **Linux Process Resource Monitoring System** is an Operating Systems
and Systems Programming project developed as part of the OSSP course.

The main purpose of this project is to understand how processes work in
a Linux operating system and to show how system resources such as **CPU
and memory** are used by running processes.

We are doing this project because many processes run at the same time in
a Linux system, and it can be difficult to understand what each process
is doing and how much of the system resources it is using. Our project
aims to make this information simple and easy to understand.

## Why Are We Doing This Project?

Through this project, we want to connect the concepts learned in the
Operating Systems and Systems Programming syllabus with a practical
Linux application.

We want to demonstrate concepts such as:

-   Process creation and process management
-   Process states and process termination
-   CPU scheduling and process execution
-   Memory management and process memory usage
-   Linux file system and file handling
-   File descriptors and Linux file I/O
-   Inter-Process Communication (IPC)
-   Pipes and signals
-   Threads and concurrency
-   Mutexes and semaphores
-   Race conditions and deadlocks
-   Linux/POSIX system programming

## What Do We Want to Show?

Our project will provide a simple way to observe running Linux processes
and their resource usage.

The system is intended to show information such as:

-   Process ID (PID)
-   Process status
-   CPU usage
-   Memory usage
-   Other useful process/resource information

The project will demonstrate how Linux provides information about
processes and how system programming techniques can be used to collect
and display that information.

## Project Objectives

1.  To monitor active Linux processes and display their basic process
    information.
2.  To monitor CPU, memory, and other important resource usage of
    running processes.
3.  To apply process management, memory management, file handling, IPC,
    and signal concepts in the project.
4.  To demonstrate threads and synchronization concepts such as mutexes
    and semaphores while monitoring processes.

## Expected Outcome

At the end of the project, we expect to have a simple Linux-based
process monitoring system that can display useful information about
active processes and their resource usage.

The project will help us understand the practical working of Linux
processes and how Operating Systems concepts can be implemented using
system programming.

## Course Connection

This project brings together the Operating Systems and Systems
Programming concepts covered in the course, including process
management, scheduling, memory management, file systems, IPC, signals,
threads, synchronization, and Linux system programming.

## Conclusion

This project is designed to make Operating Systems concepts more
practical and easier to understand. Instead of only studying how
processes and resources work in theory, we aim to demonstrate these
concepts through a working Linux-based application.
